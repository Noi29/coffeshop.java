# Cafe Java

A console cafe management game written in Java.

You run a cafe for 5 days. Serve customers before their time runs out,
manage your ingredient stock, buy upgrades and reach the daily money goal.
If your reputation drops to 0, you lose.

## How to run

Requires Java 17 or higher. Download the file and run this in a terminal,
in the folder where the file is:

    java CafeJava.java

## Features

- Customers with three urgency levels (in a hurry, normal, no rush), each with its own time limit
- A live clock that warns you as time runs out
- A menu based on 2026 food trends: pistachio croissant, Japanese egg sando, sesame toast, hot honey toast, miso caramel cookie, plus coffee and matcha drinks
- Ingredient inventory and a shop with upgrades
- A dog rule: if a customer brings a dog, you must give it a free croqueta. Forget it and you get paid half

## What I practiced

Classes and objects, enums, collections (List and Map), a thread for the live clock,
input validation with try/catch, and game loop design.
